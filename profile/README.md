# TankDev

**Software Engineering · Applied AI · Process Automation**

TankDev is a software engineering organization focused on building custom software, applied artificial intelligence systems, and automation for real operational workflows.

We work across the full engineering lifecycle — from problem analysis and system architecture to implementation, integration, deployment, and operational tooling.

Machine learning and AI systems designed around measurable technical objectives, explainability, and real implementation constraints.

**Process Automation**

**System Integration**  
Connecting software, APIs, databases, desktop tools, and existing operational systems into unified workflows.

## Selected Engineering Work

### DeepCancer

**Explainable AI for Breast Histopathology Classification**

A research project combining **Swin Transformer** and **ConvNeXt** architectures for breast histopathology image classification, with **Grad-CAM** explainability.

The published study evaluates binary and eight-class classification on the BreaKHis dataset. The binary experiment reported **98.86% accuracy**, **99.07% precision**, **99.25% recall**, and **99.16% F1-score**.

**Research & education only — not for clinical diagnosis.**

[GitHub Repository](https://github.com/TankDev-tech/deepcancer) · [Research Platform](http://deepcancer.org/) · [System Overview](https://tankdev.tech/tr/systems/deepcancer) · [Case Study](https://tankdev.tech/tr/case-studies/deepcancer) · [Published Research](https://doi.org/10.5281/zenodo.18138734)

### Web-to-Print Production Automation

**From browser-based personalization to production-ready print files**

A custom production system connecting customer-facing design workflows, order management, production operations, and Adobe Illustrator-based output generation.

The system brings multiple stages of a print-production workflow into a coordinated software architecture using technologies including **Next.js**, **FastAPI**, and **PostgreSQL**.

### Autonomous AI Video Production System

**Research-to-publishing AI production infrastructure**

An autonomous production system coordinating research, source processing, script generation, voice production, visual generation, media assembly, production controls, metadata, scheduling, and publishing.

The architecture includes **8 coordinated production stages**, **4 API budget control levels**, **2 independent production flows**, and a centralized operational control layer.

## Engineering Approach

TankDev systems are built around a few consistent principles:

- Solve the operational problem before choosing the technology
- Prefer maintainable system architecture over unnecessary complexity
- Automate repetitive work while preserving control and observability
- Treat AI as an engineering component rather than a standalone feature
- Design around real deployment and infrastructure constraints
- Document system boundaries and avoid unsupported performance claims
- Keep public technical documentation separate from proprietary implementation

## Technology
